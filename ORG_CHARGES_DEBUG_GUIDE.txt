DEBUGGING STEPS FOR USER:
================================================================================

Step 1: VERIFY API RESPONSES
-----------------
Open browser DevTools (F12) and go to Network tab, then:

1. Go to Patient Registration page
2. Select an organization from dropdown
3. Look for API call: GET /master/organizations/{orgId}/charges
4. Check response in DevTools:
   ✓ Should see "success": true
   ✓ Should see "data": [array of charges]
   ✓ Each charge should have: testId, b2cCharge, b2bCharge
   ✓ NO errors or empty array

If API response is wrong, check backend logs:
   - Backend might not be returning charges for that organization
   - Run: node test-charges-api.js (in backend folder)


Step 2: VERIFY FRONTEND CONSOLE LOGS
-----------------
1. Open browser DevTools Console (F12)
2. Clear console (type: clear())
3. Select different organization
4. Look for logs with 📡 📥 💰 🔄 emojis:
   
   Should see:
   📡 Fetching charges for organization: ORG-AAA
   📥 Raw charges response: [array with charges]
   💰 Organization charges map created: {key: value pairs}
   🔄 Updating X selected tests with org charges...
   
   Each test should show: ✅ Test "Name" (ID: 1): B2C 100→330
   
   If seeing ❓ instead of ✅ means:
   - Test ID in selectedTests doesn't match charge testId
   - String conversion failed
   - ChargeMap is empty


Step 3: TEST COMPLETE FLOW (FRESH PAGE)
-----------------
1. Clear browser cache: CTRL+SHIFT+DEL → select All time, Cookies & cache
2. Clear localStorage: Open DevTools Console and run:
   localStorage.clear()
3. Refresh page (F5)
4. Manually add 2-3 tests (don't select organization yet)
5. Verify tests show DEFAULT charges (e.g., 100, 150, 200)
6. Select organization from dropdown
7. Check DevTools console for logs (Step 2)
8. Verify tests NOW show ORGANIZATION charges (e.g., 330, 313, 554)
9. Refresh page (F5)
10. Check if organization and tests are still selected
11. Check if charges match ORGANIZATION charges (not defaults)


Step 4: CHECK BROWSER STORAGE
-----------------
In DevTools → Application → Local Storage → http://localhost:3000

Look for key: "patientRegistration_v2"

It should contain:
   {
     "selectedOrganization": "ORG-AAA",
     "organizationSearch": "Main Lab",
     "selectedTests": [
       {"id": 1, "name": "Test 1", "b2cCharge": 330, ...},
       {"id": 2, "name": "Test 2", "b2cCharge": 313, ...}
     ]
   }

If localStorage shows DEFAULT charges instead of ORG charges:
   - Tests are being saved before organization charges are applied
   - May need to wait for async charge fetch to complete before saving
