UNDERSTANDING THE OUTPUT:

1️⃣  Request Details
    Shows what API is being called and with what parameters

2️⃣  Response Status
    HTTP status code:
    • 200 OK = Request successful
    • 404 Not Found = Resource doesn't exist
    • 500 Server Error = Backend problem
    • Other codes indicate different issues

3️⃣  Raw JSON Response
    The complete, formatted JSON response from the API
    This is what your code will receive

4️⃣  Detailed Field Analysis
    Breaking down each field in the response:
    • Field name
    • Field value
    • Field data type in parentheses

5️⃣  Summary Statistics
    High-level overview of the data:
    • How many charges returned
    • Diversity of data (unique tests/organizations)
    • Price averages

════════════════════════════════════════════════════════════════════════════════════

INTERPRETING FIELD TYPES:

string      → Text enclosed in quotes: "ORG-AAC"
number      → Numbers without quotes: 500, 2.5
boolean     → true or false keywords
null        → Nothing/Not set
array       → Ordered list: [item1, item2, ...]
object      → Structured data: {key: value, ...}

════════════════════════════════════════════════════════════════════════════════════

KEY OBSERVATIONS:

• "success": true
  ✓ Indicates the API call succeeded
  ✓ Data should be valid and complete

• "data": []
  ✓ Array is empty
  ✓ No charges found for this organization
  ✓ Could mean: no charges exist, all are inactive, or org ID is wrong

• "discountPercent": null
  ✓ No discount for this charge
  ✓ Use full price

• "effectiveTo": null
  ✓ Charge has no expiration
  ✓ Valid indefinitely

• "isActive": true
  ✓ This charge is currently being used
  ✓ Should appear in customer pricing

• "createdAt": "2025-01-15T10:30:00.000Z"
  ✓ ISO 8601 format (UTC timezone)
  ✓ "Z" means Zulu/UTC time
  ✓ Represents: Jan 15, 2025 at 10:30 AM UTC

PRACTICAL EXAMPLES:

Example 1: Price Calculation
────────────────────────────
Charge: {"b2cCharge": 500, "b2bCharge": 450, "discountPercent": 5}

For B2C customer:
  Price = 500
  
For B2B customer:
  Price = 450 (already lower)
  
If discount applies:
  Price = 450 * (1 - 5/100) = 450 * 0.95 = 427.50

Example 2: Checking if Valid
────────────────────────────
{
  "effectiveFrom": "2025-01-01T00:00:00.000Z",
  "effectiveTo": null,
  "isActive": true
}

Interpretation:
✓ Started on Jan 1, 2025
✓ No expiration (still valid)
✓ Currently active
✓ Can use this price now
