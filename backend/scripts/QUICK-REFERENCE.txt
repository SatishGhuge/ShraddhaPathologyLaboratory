API ENDPOINT:
  GET http://localhost:5000/api/master/organizations/{organizationId}/charges

RESPONSE STRUCTURE:
{
  "success": true|false,
  "data": [
    {
      "id": "string",              // Charge record ID
      "testId": 123,               // Test ID
      "organizationId": "ORG-AAC", // Organization ID
      "b2cCharge": 500,            // B2C price
      "b2bCharge": 450,            // B2B price
      "discountPercent": null,     // Discount percentage
      "specialPrice": null,        // Special pricing
      "effectiveFrom": "ISO-8601", // Effective from date
      "effectiveTo": null,         // Expiration date
      "isActive": true,            // Is active
      "createdAt": "ISO-8601",     // Created timestamp
      "updatedAt": "ISO-8601",     // Updated timestamp
      "test": {                    // Nested test object
        "id": 123,
        "name": "Complete Blood Count",
        "shortName": "CBC",
        "departmentId": 2,
        "department": {
          "name": "Hematology"
        }
      },
      "organization": {            // Nested organization object
        "id": "ORG-AAC",
        "name": "Alandi Branch",
        "location": "Alandi, Pune"
      }
    }
  ]
}

DATA TYPES:

string      → "ORG-AAC", "Complete Blood Count"
number      → 500, 2.5, 0
boolean     → true, false
null        → null (no value)
array       → [...] (list of items)
object      → {...} (structured data)
ISO 8601    → "2025-01-15T10:30:00.000Z" (UTC timestamp)

═══════════════════════════════════════════════════════════════════════════════════

KEY FIELDS:

Top Level:
  success     → Boolean indicating request success
  data        → Array of charge records

Charge Record:
  id          → Unique charge record identifier
  testId      → Foreign key to Test
  organizationId → Foreign key to Organization
  b2cCharge   → Consumer pricing
  b2bCharge   → Business pricing
  isActive    → Whether charge is currently active
  createdAt   → When record was created (UTC)
  updatedAt   → When record was last modified (UTC)

Nested - test object:
  id          → Test ID
  name        → Full test name
  shortName   → Abbreviated name
  department  → Department info (with name)

Nested - organization object:
  id          → Organization ID
  name        → Organization name
  location    → Physical location

TROUBLESHOOTING:

Problem: Connection refused
Solution: Ensure server is running → npm run dev (in backend)

Problem: Empty data array
Solution: 1) Check organization ID exists
          2) Verify charges are marked isActive: true
          3) Check organization has test charges

Problem: 404 Not Found
Solution: Verify the organization ID is correct

Problem: Cannot execute script (Windows)
Solution: Run PowerShell as Administrator then:
          Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Problem: Permission denied (Linux/Mac)
Solution: Make script executable → chmod +x scripts/inspect-org-charges.sh

Problem: jq command not found (Bash)
Solution: Install jq:
          • macOS: brew install jq
          • Ubuntu: sudo apt-get install jq
          • CentOS: sudo yum install jq

UNDERSTANDING NULL VALUES:

"effectiveFrom": null    → No effective date set (always effective)
"effectiveTo": null      → No expiration (indefinitely valid)
"discountPercent": null  → No discount applied
"specialPrice": null     → No special pricing in effect
"location": null         → Location not specified

═══════════════════════════════════════════════════════════════════════════════════

UNDERSTANDING ISO 8601 TIMESTAMPS:

Format: YYYY-MM-DDTHH:MM:SS.SSSZ

Examples:
  2025-01-15T10:30:00.000Z  → Jan 15, 2025 at 10:30 AM UTC
  2025-12-31T23:59:59.999Z  → Dec 31, 2025 at 11:59:59 PM UTC

All timestamps are in UTC (Z = Zulu time = UTC)
